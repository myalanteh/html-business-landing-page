# HTML Business Landing Page

A clean and responsive static business website built with HTML and CSS.

- Responsive landing page
- Hero section
- Services section
- Work/portfolio section
- Pricing section
- Contact call-to-action
- Clean modern design

## Technologies

- HTML5
- CSS3
- Responsive Design

## How to Use

Open `index.html` in your browser.

This project is suitable for showing front-end layout, responsive design, and clean website structure skills.
